# BMW N54 Fuel Injector Replacement - Step by Step

## Application
**Engine**: N54 (twin-turbo 3.0L I6)
**Vehicles**:
- E82/E88 135i (2008-2013)
- E90/E91/E92/E93 335i (2007-2013)
- E60/E61 535i (2008-2010)
- E71 X6 35i (2008-2014)

**Common Issue**: Index 12 injectors fail, causing rough idle, misfires, and rich/lean codes

---

## Before You Start

### **Symptoms of Failed N54 Injectors:**
- Rough idle, especially when cold
- Misfires (P030X codes)
- Fuel smell from exhaust
- Rich codes (P0172, P0175) or lean codes
- Long crank time before start
- Black smoke from exhaust

### **Which Injectors?**
- **Index 12 injectors** (2007-2009) - FAIL frequently
- **Index 13 injectors** (2010-2013) - More reliable but still fail

**How to check your index:**
1. Use INPA or ISTA to read injector index
2. Or check production date on injector body

**Replacement strategy:**
- If Index 12: Replace ALL 6 with updated version
- If Index 13: Can replace individual failed injectors

---

## Parts Required

### **Injectors** (recommend replacing all 6):
- **Updated injectors**: 13 53 7 585 261-03 (set of 6, latest revision)
- **OEM alternative**: Bosch 0 261 500 232
- **Cost**: ~$1800-2400 for set of 6

### **Additional parts needed:**
- Injector seals/O-rings: 13 53 7 585 657 (set) - ~$30
- Decoupling elements (rubber insulators): 13 53 7 546 244 (x6) - ~$60
- Index 12 to Index 13 upgrade kit includes all seals

### **Fluids:**
- Engine oil (if changing during job): ~7 qts
- Coolant (minimal loss): BMW coolant

### **Optional but recommended:**
- Valve cover gasket if leaking: 11 12 7 585 907
- Spark plugs: Replace while you're in there

## Tools Required

### **Essential:**
- 5mm, 6mm, 8mm, 10mm hex/Allen keys
- T25, T27, T30 Torx drivers
- 10mm, 13mm sockets and wrenches
- Fuel line disconnect tool (or small flathead screwdriver)
- Torque wrench (10-50 ft-lb range)
- Injector puller tool or large flathead screwdriver
- Pick set or small hook tool

### **Recommended:**
- BMW N54 injector removal tool (makes job much easier)
- Magnetic pickup tool
- Parts tray (lots of small bolts)
- Vacuum or shop air (clean rail area)

### **Coding tool:**
- **REQUIRED**: INPA, ISTA+, or dealer visit
- Cannot simply swap injectors - MUST code new injectors to DME

## Procedure

### **Step 1: Preparation (15 minutes)**

1. **Relieve fuel pressure:**
   - Remove fuel pump fuse (fuse box in glovebox or trunk)
   - Start engine, let it run until it stalls
   - Try to start again to ensure pressure is relieved

2. **Disconnect battery:**
   - Trunk, right side
   - 10mm to disconnect negative terminal first
   - Secure cable away from battery

3. **Remove engine cover:**
   - Pull straight up (no tools needed)
   - Set aside

**CRITICAL SAFETY:**
- Work in well-ventilated area
- Have fire extinguisher nearby
- No smoking or open flames
- Fuel will spill - have rags and drain pan ready

---

### **Step 2: Remove Intake Components (30 minutes)**

4. **Remove charge pipe** (turbo to throttle body):
   - Loosen clamps at both ends
   - Disconnect PCV hose from valve cover
   - Lift charge pipe out

5. **Remove intake manifold:**
   - Disconnect DISA valve connector (right side of manifold)
   - Remove 6x 10mm nuts holding manifold to head
   - Disconnect brake booster vacuum line (under manifold)
   - Carefully lift manifold off - don't lose O-ring seals
   - Cover intake ports with tape or rags (prevent debris falling in)

**Watch out for:**
- Manifold O-rings falling into engine
- Wiring harness routing (mark with tape if needed)

---

### **Step 3: Access Fuel Rails (20 minutes)**

6. **Remove ignition coils:**
   - Unplug each coil connector (press tab, pull straight up)
   - Remove 5mm hex bolt from each coil
   - Pull coils straight up (wiggle if stuck)
   - Set aside in order

7. **Remove valve cover** (optional but recommended for access):
   - Disconnect CCV hoses from valve cover
   - Remove 8x T30 Torx bolts around perimeter
   - Lift off valve cover carefully
   - **If valve cover gasket is old**, replace it while you're here

**Alternative:** Can do job without removing valve cover, but access is tight

8. **Clean area around fuel rail:**
   - Use vacuum or compressed air
   - Critical: No debris can fall into injector holes

---

### **Step 4: Remove Fuel Rails and Injectors (45 minutes)**

9. **Disconnect fuel lines:**
   - High-pressure fuel line: Use 17mm wrench to hold rail fitting, 17mm to loosen line
   - Fuel return line: Press release tabs with fuel line tool or small screwdriver
   - **Fuel will spill** - have rags ready

10. **Disconnect injector electrical connectors:**
    - Each injector has a connector on top
    - Press tab, pull straight up
    - Mark cylinder numbers if reusing any injectors

11. **Remove fuel rail mounting bolts:**
    - 2x 10mm bolts per rail (4 total - 2 per bank... wait, N54 is inline-6, single rail)
    - Actually: 4x 6mm hex bolts hold rail down

12. **Remove fuel rail:**
    - Gently pry up on rail evenly (use two pry points)
    - Rock rail side to side while pulling up
    - Injectors will come out with rail
    - **If injectors stick in head:** Use injector puller tool or carefully pry

13. **Remove injectors from rail:**
    - Note position of each injector
    - Pull retaining clip off each injector (use pick)
    - Twist and pull injector out of rail
    - Remove and discard all old O-rings and seals

**CRITICAL WARNING:**
- **Injector tip is delicate** - do not drop or hit injector
- Check for debris in injector bores - clean if needed
- Injector seats must be clean and smooth

---

### **Step 5: Install New Injectors (45 minutes)**

14. **Prepare new injectors:**
    - Lubricate new O-rings with clean engine oil or gasoline
    - Install O-rings on each injector:
      - Upper O-ring (fuel rail seal)
      - Lower O-ring (cylinder head seal)
    - Install decoupling element (rubber insulator) on each injector

15. **Install injectors into fuel rail:**
    - Align injector tab with slot in rail
    - Push firmly until seated
    - Install retaining clip (should snap into place)
    - Verify each injector is locked in place

16. **Install fuel rail with injectors:**
    - Lubricate lower O-rings with oil
    - Align all 6 injectors with bores in head
    - Press down evenly on rail until all injectors seat
    - **Don't force** - should go in smoothly if aligned
    - Install 4x rail mounting bolts: **Torque to 7 ft-lb**

17. **Connect fuel lines:**
    - High-pressure line: Hand-tighten, then torque to 18 ft-lb
    - Return line: Push in until click
    - Tug to verify locked

18. **Connect injector electrical connectors:**
    - Press each connector onto injector until click
    - Verify locked (pull gently)

---

### **Step 6: Reassembly (30 minutes)**

19. **Reinstall valve cover** (if removed):
    - Clean mating surfaces
    - New gasket if needed
    - Install cover, torque bolts to 7 ft-lb in cross pattern

20. **Reinstall ignition coils:**
    - Install in correct cylinders
    - Push down firmly (should seat with soft click)
    - Install 5mm hex bolts: Torque to 7 ft-lb
    - Connect coil connectors

21. **Reinstall intake manifold:**
    - New O-rings recommended
    - Align manifold, press down evenly
    - Install 6x 10mm nuts: Torque to 7 ft-lb
    - Connect DISA valve connector
    - Connect brake booster vacuum line

22. **Reinstall charge pipe:**
    - Connect PCV hose
    - Tighten clamps at both ends

23. **Reconnect battery:**
    - Positive first, then negative

24. **Reinstall fuel pump fuse**

---

### **Step 7: CODING (REQUIRED - 30 minutes)**

**This step is NOT optional. Engine will not run properly without coding.**

25. **Code new injectors to DME:**

**Using INPA:**
1. Connect INPA cable to OBD port
2. Key to position 2 (dash lights on, engine off)
3. INPA → F5 (Identify vehicle)
4. Select DME / DDE
5. F6 (Job)
6. F3 (Test Plan)
7. Select "Injector Programming"
8. Follow prompts to enter new injector data:
   - Injector correction codes (on each injector body)
   - Read 6-digit code from each injector
   - Enter into corresponding cylinder
9. Execute programming
10. Wait for "Programming OK"

**Using ISTA+ or dealer:**
- More automated, but same concept
- Vehicle will auto-detect new injectors and prompt for codes

**If you don't have coding tool:**
- Drive to dealer or indie shop with INPA/ISTA
- Cost: $150-300 for coding

**CRITICAL:** Without coding, injectors will run on default values:
- Rough idle
- Misfires
- Won't pass emissions

---

### **Step 8: Prime and Test (20 minutes)**

26. **Prime fuel system:**
    - Key to position 2 (don't start)
    - Wait 5 seconds (fuel pump primes)
    - Key off
    - Repeat 3 times
    - **Check for fuel leaks** around rail and lines

27. **Start engine:**
    - Engine may run rough for 10-30 seconds (clearing air from system)
    - Should smooth out quickly
    - Check for leaks again

28. **Test drive:**
    - Drive normally for 10-15 minutes
    - Check for smooth idle, good throttle response
    - No misfires or rough running

29. **Clear codes and verify:**
    - Clear any stored codes
    - Drive 20+ miles (mix of city and highway)
    - Re-scan for codes
    - Should be clean

## Common Mistakes

1. **Not relieving fuel pressure before opening system**
   - Fuel spray = injury and fire hazard

2. **Dropping debris into cylinder head**
   - Cover open ports with tape/rags

3. **Damaging injector tips**
   - Handle carefully, don't drop

4. **Not lubricating O-rings**
   - Dry O-rings tear during installation

5. **Over-torquing plastic components**
   - Valve cover, manifold = 7 ft-lb only

6. **Not coding injectors**
   - Engine will run like crap

7. **Mixing up injector correction codes**
   - Each injector has unique code - enter correctly

## Maintenance Notes

**After replacement:**
- Injectors should last 100k+ miles (Index 13)
- Use quality fuel (Top Tier brands)
- Keep up with oil changes (dirty oil affects high-pressure fuel pump)

**Related maintenance while you're in there:**
- Replace spark plugs if >60k miles
- Replace valve cover gasket if leaking
- Check ignition coils (common failure on N54)
