# BMW Paint Color Codes Database

## How to Find BMW Paint Code

**Location:** Driver's side door jamb or B-pillar
**Label:** White sticker with VIN and paint code
**Format:** 3-digit code (e.g., 300, A52, C3M)

**Alternative locations if not on door jamb:**
- Trunk lid or trunk jamb
- Under hood on core support
- Service booklet

## Paint Code Formats

### **3-Digit Numeric (e.g., 300, 668)**
- Older BMW coding system
- Common on 1990s-2000s models
- Still used for some solid colors

### **Letter + Number (e.g., A52, B15)**
- Modern BMW system (2000s+)
- Most common current format

### **P-Series (e.g., P0P, P0R)**
- Premium/special colors
- Often Individual program colors
- May cost more for touch-up

### **C-Series (e.g., C3M, C22)**
- Current generation coding
- 2015+ models

## Finding Paint Code from VIN

**If paint code label is missing:**

1. **Call BMW dealer with VIN**
   - They can look up original factory paint code
   - Free service

2. **Use online VIN decoder**
   - Some sites decode BMW VINs to paint code
   - Not always accurate for resprays

3. **Visual match at paint shop**
   - Spectrophotometer can analyze color
   - Won't give you code, but can mix match
   - Accuracy: 90-95% (not perfect)

## Paint Types

### **Solid (Non-Metallic)**
- No metallic flakes
- Easier to touch up
- Examples: Alpine White (300), Jet Black (C22)
- **Mixing:** Single-stage or base + clear

### **Metallic**
- Contains metallic flakes
- Harder to match (angle-dependent)
- Examples: Black Sapphire (668), Mineral White (P0P)
- **Mixing:** Base + clear (two-stage)

### **Matte/Frozen**
- No gloss finish
- Extremely difficult to repair
- **NEVER** polish or wax
- Requires special matte clear coat
- Examples: Frozen Silver (P0R)

### **Pearl**
- Contains pearl/mica particles
- Very difficult to match
- Often shows color shift in different light
- **Mixing:** Base + pearl + clear (three-stage)

## Touch-Up Paint Notes

### **Where to Buy:**
1. **BMW Dealer Parts** - Most accurate, expensive ($25-40 per pen)
2. **Dr. ColorChip** - Good quality, color-matched ($60-80 kit)
3. **Automotive paint suppliers** - Can mix exact code ($20-50)
4. **Online (PaintScratch, etc.)** - Hit or miss on color match ($15-30)

### **Application Tips:**
- Clean area thoroughly first
- Apply in thin layers (multiple coats better than one thick coat)
- Allow drying time between coats
- Metallic colors: Keep spray can moving to avoid flake patterns
- Clear coat after color coat dries (metallic/pearl only)

### **Matching Issues:**
- Faded original paint won't match fresh touch-up
- Metallic orientation affects appearance
- Age of car = more fading = harder to match
- Full panel respray may be needed for good blend

## Special Cases

### **BMW Individual Colors**
- Custom colors not in standard database
- Paint code still on door jamb
- May require BMW dealer to mix
- Touch-up paint harder to source

### **Repainted Vehicles**
- Door jamb code may not match actual color
- Check inside trunk/door for overspray
- If colors don't match, car has been repainted
- Visual match required

### **Tri-Coat Colors**
- Some white pearls and special colors use 3 layers
- Base + mid coat + clear
- Very difficult to touch up
- Examples: Some Individual whites

## Paint Code Verification

**Before ordering paint:**

1. **Verify code on label is readable**
   - Faded labels can be misread
   - 300 vs 380, A52 vs A62, etc.

2. **Cross-reference with year/model**
   - Some codes were only used certain years
   - Helps confirm code is correct

3. **Visual comparison**
   - Look up images of the color online
   - Does it match your car?

4. **Test on hidden area first**
   - Apply touch-up to inside door jamb or trunk
   - Verify match before doing visible area

## Common Misidentifications

**Alpine White III (300) vs Mineral White (P0P):**
- 300 = Pure white, solid
- P0P = Pearl/metallic white, slightly warmer
- Look very similar in photos, different in person

**Black Sapphire (668) vs Jet Black (C22):**
- 668 = Metallic black with blue flake
- C22 = Solid black, no metallic
- Hard to tell in low light

**Space Gray (A83) vs Mineral Gray (A96):**
- A83 = Cooler gray
- A96 = Warmer gray with green undertone
- Both look similar in photos
