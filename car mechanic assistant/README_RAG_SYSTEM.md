# Gemini/ChromaDB mechanic manual assistant

The current implementation and supported commands are documented in [QUICKSTART.md](QUICKSTART.md). Every rebuild feature and verification result is recorded in [BUILD_STATUS.md](BUILD_STATUS.md); remaining targets and their evidence requirements are in [RESUME_DELIVERY_PLAN.md](RESUME_DELIVERY_PLAN.md).

This is an October 2026 rebuild of the earlier prototype. It uses a supported Gemini SDK, canonical Chroma applicability filters, generic-source inclusion, folder/code/entity reranking, bounded chunks, PDF/DOCX/Markdown ingestion, source locations, private feedback capture and a retrieval-only evaluator.

The included 14 Markdown notes are development material. They do not establish a 500-page authorised repair corpus. Eight old keyword smoke questions do not establish 90% retrieval precision. Workshop use by 24 mechanics, a month of structured review, first-AI status and six-month adoption remain unverified targets.

Text PDFs and DOCX in English/Chinese/Japanese are fixture-tested. Image-only PDFs require OCR, which is pending. Source data, built indexes, API credentials and feedback are excluded from Git.
